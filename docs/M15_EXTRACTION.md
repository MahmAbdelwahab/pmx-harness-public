# Working with ICH M15 in the harness

ICH M15, *General Principles for Model-Informed Drug Development*, provides the framework for the harness's planning and reporting templates. Consult Sections 2–4 and Appendices 1–2 of the final guideline. [Official ICH M15 guideline](https://database.ich.org/sites/default/files/ICH_M15_Step4_Final_Guideline_2026_0129.pdf)

## Frame the question and the model's role

Start with the decision the analysis will inform. Describe the model's role, the data it uses and how those data relate to the intended use. In the [assessment table](../templates/assessment-table.md), explain how much weight the decision places on the model and what could happen if the decision were wrong. Use those two judgments to justify the model risk rating. Assess model impact separately by explaining how the proposed strategy relates to the applicable regulatory standard or expectations. Record one table per question and keep the detailed analysis in the plan and report.

## Plan the evaluation before execution

Use the [Model Analysis Plan](../templates/MAP.md) to specify data selection, transformations, assumptions, analysis methods and evaluation criteria. The harness requires approval of the plan before data assembly. Make the criteria measurable and tie them to the proposed use. Describe how deviations and unmet criteria will be handled.

Distinguish checking the code, equations and calculations from evaluating how well the model describes or predicts the relevant data. Then consider whether the evidence supports the intended use. Match the depth of evaluation to the model risk. Explain how uncertainty, sensitivity and, when applicable, independent evaluation affect the interpretation. Address concerns specific to the chosen method, such as overfitting in machine-learning models.

## Report the results and preserve the evidence

Use the [Model Analysis Report](../templates/MAR.md) to document the analysis and compare its results with the planned criteria. Explain deviations and limitations, include the plan as an appendix when it was developed, and cross-reference the report and the assessment table. Keep the data definitions, analysis code, computational records and supporting files needed to trace the reported findings, and arrange access through the appropriate review process.
