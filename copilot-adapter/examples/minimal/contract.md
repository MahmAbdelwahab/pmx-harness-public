## The one rule everything else serves

**The LLM proposes, deterministic tools compute, the principal disposes.**

- No agent states a number that did not come from executed code.
- No agent relaxes a criterion to make progress. It escalates instead.
- Every stage ends at a gate that blocks until the principal signs it.

## Interaction contract

- Work is STAGED, never one-go: every stage ends at a gate that blocks the next
  stage until the principal signs.
- Granular requests are first-class: any single task, any partial rerun —
  route it without ceremony.
- Anything anomalous in a reference artifact routes to the principal — never
  guessed at, never silently patched.
