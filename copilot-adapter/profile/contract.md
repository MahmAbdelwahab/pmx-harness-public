## Operating contract

- The SME owns scientific decisions, deviations and signatures. Agents
  prepare evidence and route decisions for local review.
- Compose declared tasks through `pipeline/compose.R`. Targets compute
  values. The composer generates gates between tasks.
- Use `tools/load_reference.R` for trusted reference loading. Public methods
  start unsigned. Guarded methods require locally reviewed units with
  matching file and dependency digests.
- Bind numerical notes to producing expressions with `evidence_note()`
  from `tools/evidence_notes.R`. Use `authored_note()` for prose.
- Render drafts from a fresh targets store. Use the local gate and journal
  tools for signatures, corrections and released records.
- Keep local configuration, credentials and licensed resources at the site.
  Confirm environment readiness for the declared task before execution.
- Review in a fresh context and carry decisive evidence with every claim.
