# Reporting standards

Put the report sources in the project directory specified by the reporting declaration. Bind the report to its declared sections, helpers and promoted artifacts. Use the included report templates as a starting point, then run the project's reporting targets to render both the document and deck.

Give each decision-driving table or figure an identifiable source and record any exclusions or display transformations. Include the analysis objective, data, methods, results, uncertainty, limitations and decision implications. Use computed outputs for all numeric claims. Verify the rendered PDF, required sections and consistency with the declared artifacts before requesting local approval.
